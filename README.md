# PMO Project Tracking Dashboard (Excel)

##  Project Overview

This project is an Excel-based dashboard designed to track and manage multiple projects. It helps monitor project status, analyze data, and generate quick reports for decision-making.

## Objectives
* Track project progress (Completed, In Progress, Pending)
* Provide summary of total projects
* Visualize data using charts
* Enable easy filtering of project data

## 🛠 Tools Used
* Microsoft Excel
* Pivot Tables
* Charts (Pie/Bar)
* Data Validation (Dropdown)
* Conditional Formatting
* Excel Formulas (COUNTIF, COUNTA)

## Features
* KPI Section (Total, Completed, Pending, In Progress)
* Project Data Table
* Status-based color highlighting
* Interactive dashboard with filters (Slicers)
* Graphical representation of project status

## Project Structure
* Sheet1 → Project Data
* Dashboard → KPI & Charts
* Pivot → Pivot Table for analysis

## How It Works
1. Enter project details in the data sheet
2. Select status using dropdown (Completed, In Progress, Pending)
3. Dashboard automatically updates using formulas
4. Pivot table generates summary
5. Charts visualize project data

## 🚀 Conclusion
This project demonstrates basic PMO reporting using Excel. It shows how data can be organized, analyzed, and presented in a simple dashboard for better decision-making.
